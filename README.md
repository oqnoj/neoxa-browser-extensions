# Neoxa Browser Extensions 🚀
Lightweight, gaming-PC friendly browser extensions for tracking live prices from the [Neoxa Exchange](https://neoxa.exchange) API. 

Designed specifically with **gaming PCs** in mind — they run entirely via background workers and browser alarms, consuming **zero CPU/RAM** when your browser is closed during gaming sessions.

---

## Available Extensions

### 1. [v1-xbt-tracker](./v1-xbt-tracker)
* **What it is:** A dedicated, single-asset toolbar ticker built specifically for **XBT (BTCB2)** — the unique Blake2b Bitcoin asset traded exclusively on Neoxa Exchange.
* **Features:** Shows a clean rounded price on your toolbar icon and displays the full exact price with decimals when clicked.

### 2. [v2-multi-prices-ticker](./v2-multi-prices-ticker)
* **What it is:** A fully customizable multi-asset tracker. 
* **Features:** Includes a dedicated settings page where you can check/uncheck any token you want to monitor, choose which token to pin to your toolbar badge (with smart shorthand formatting like `81.3K`), and view them all in a clean popup list.

## 🛠️ How to Install (For Beginners)
You don't need to know how to code to use these! Follow these simple steps for any of the versions above:

1. **Download the code:** 
   * Click the green **Code** button at the top of this GitHub repository page and select **Download ZIP**.
   * Unzip (extract) the downloaded ZIP file somewhere easy to find on your computer (like your Desktop).
2. **Open your browser extensions page:**
   * Open **Brave**, **Chrome**, or **Microsoft Edge**.
   * Type `brave://extensions/` (or `chrome://extensions/`) into your address bar and hit Enter.
3. **Turn on Developer Mode:**
   * Look at the **top-right corner** of that extensions page and toggle the **Developer mode** switch to **ON**.
4. **Load the extension:**
   * Click the **Load unpacked** button that appears in the top-left corner.
   * Select the folder of the extension you want to use (e.g., the `v1-xbt-tracker` folder or `v2-multi-prices-ticker` folder).
5. **Pin it:**
   * Click the puzzle piece icon 🧩 in your browser's top toolbar and click the pin icon next to your new Neoxa extension so it's always visible!
